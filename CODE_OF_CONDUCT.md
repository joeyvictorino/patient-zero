# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, argue with the evidence and not the person. Harassment and personal attacks are not tolerated.

Two things specific to this project:

- **No real patient data, ever,** in issues, pull requests, test fixtures, screenshots or logs. Posts that contain it are removed, and the poster is told how to report the exposure where they work.
- **No naming and shaming.** If patient-zero helped you find a flaw in someone's product, that goes to them. Issues here are about the tool and the standard.

To report a conduct problem, use GitHub's report feature on the comment itself, or contact the project lead through their GitHub profile.
