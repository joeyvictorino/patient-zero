# Vibe Clinic: an app with the usual mistakes

A small, fake visit-notes app, written the way a first draft from an AI coding tool often comes out. Every file here is wrong on purpose, and none of it is real: no real keys, no real patients.

```
pz check examples/vibe-clinic
```

It exists so you can see what `pz check` says before pointing it at your own project. It is not meant to run.
